### Added

- Mesh map: each node's name carries how it reaches you, the SNR of a node heard direct or its hop count, coloured by hops, so a signal report can be read straight off the map. A Names switch names every node, overlaps and all, instead of only the ones that fit.
- Mesh map: a click on a node opens a card at it with its hops, the SNR each way, distance and last heard, and buttons for Traceroute, Message, Position, Telemetry, Neighbours and Copy report (its name, how you hear it and the last traceroute, as text). Esc or a click on the map puts it away.
- Mesh map: a traceroute's path shows each leg's SNR next to the node that heard it, there and back, and names every relay on the way.
