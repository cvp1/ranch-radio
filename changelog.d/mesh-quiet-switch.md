### Added

- The Mesh tab has an "Auto-trace" switch for each node. Off stops the station's automatic traceroutes at once (the queue and any armed timer go too), so the node sends only what a page or the feed asks; on starts them again. The choice is kept across restarts beside the add-on state file and wins over the host file's `auto_trace`; a kept file that cannot be read starts every node off.
